Tiny but mighty.

bee is a coding agent harness shipped as one Go binary. Give it a task and it can edit code, run tests and commit changes. Use a 4k-context model on your machine or connect a hosted API. The workflow stays the same.

Why bee

Three ideas, one binary.

The same tools work with small local models and larger hosted models.

4k

Tiny-context friendly

bee limits the tokens spent on its system prompt, tool docs, tool output and memory. Memories are loaded only when relevant. There are no model profiles to manage; for a 4k-context Ollama model, lower a few budgets in your config. Long sessions compact older history.

>_

Skills are subcommands

Put a markdown file in ~/.bee/skills, then invoke it with bee <name>. It works from any directory and shell. bee remains the only executable you need on your PATH.

fn

Skills are agent endpoints

A skill can contain a prompt, an executable command or a multi-step recipe. Executable skills are available to the model as tools during a task. Recipes handle shell and tool steps in Go; the model is called only for steps that need one.

Also included: loop detection, recovery nudges when a model stalls, sandboxing and approval prompts for risky commands.

The colony

More than one bee.

The binary also includes agent roles, parallel workers and an unattended overnight mode. Use them when you need them.

Three roles

worker edits files and runs commands. scout handles read-only research, including web search. queen divides larger tasks among hive workers. Press shift+tab to switch roles.

A hive that stays aligned

Each worker receives a pheromone card with the shared goal, plan and status of the other workers. If a worker stops unexpectedly, its report includes context about the work already done.

Parallel agents

bee agents runs each task in a separate git worktree. When a task finishes, bee rebases its branch, runs your verify gate and fast-forwards main.

Overnight loop

bee zzz works in small iterations. Each iteration ends in a commit or rollback, leaving a branch that is easy to inspect and revert.

🌼 committed🍃 noop🥀 reset💥 failed

Procedure memory

bee notices repeated read-only tool sequences and saves them as runnable shortcuts called waggles. Replaying a route avoids extra model round trips, which is especially useful with small local models.

Review aids

Use bee explain to review the files changed by each request and their recorded reasons. bee quiz hides a reason until you make a guess. Both help you follow the agent's work and learn the codebase.

Quick start

Up and running in a minute.

  1. Install

    $ curl -fsSL https://raw.githubusercontent.com/elhenro/bee/main/install.sh | sh

  2. Pick a model

    Start bee, open /model, then select a runtime and model. Local options include oMLX, Ollama and LM Studio; hosted providers include OpenRouter.

  3. Hand it a job

    Use the interactive terminal UI or bee run for headless jobs. Additional workflows are available as subcommands.

    $ bee criticize plan.md            # a skill is a subcommand
$ bee run "lint cmd/"              # headless, pipeable
$ bee swarm "migrate auth to jwt"  # queen plans, workers build
$ bee fan "audit internal/"        # same prompt, many bees
$ bee zzz "tighten error messages" # overnight loop
$ bee agents                       # parallel agents, one worktree each
$ bee remote-control               # drive bee from another device on your LAN
Local first

Made for local models.

bee connects to Ollama and oMLX for local inference. You do not need an API key or hosted account, and there are no provider rate limits. Your prompts and code stay on your machine.

On macOS, oMLX uses Apple Silicon acceleration and prompt caching to improve speed and memory efficiency. If your coding model accepts text only, bee can send images to a separate local vision model.

FAQ

What is bee?

bee is an open-source coding agent harness written in Go. It gives an LLM tools to edit code, run tests and commit changes. Install one static executable; no language runtime or background daemon is required.

How do I install bee?

Run curl -fsSL https://raw.githubusercontent.com/elhenro/bee/main/install.sh | sh. If you have Go, use go install github.com/elhenro/bee/cmd/bee@latest instead. After installation, start bee and use /model to select a runtime and model. Local options include oMLX and Ollama; OpenRouter is available for hosted models.

Can bee run fully local and offline?

Connect bee to Ollama or oMLX and your prompts and code stay on your machine. No API key is required, and there are no provider rate limits. By default, bee checks GitHub for updates once per hour. Set update_check = "off" to disable that check. On macOS, oMLX provides Apple Silicon acceleration and prompt caching.

What hardware do I need to run bee locally?

That depends on the model. On a MacBook M3 Max with 64 GB RAM, I run a 17 GB Qwen3.8-27B and a 22 GB 35B-A3B model. A 7 GB model such as MiMo-V2.6 9B needs much less memory. A modern laptop with 16 to 32 GB RAM is a reasonable place to start with smaller models.

Which models work well with bee?

My local reference is Qwen3.8-27B (oQ4e, with multi-token prediction) on oMLX. I also run Ornith-1.5-35B-A3B and MiMo-V2.6 9B. bee supports hosted frontier APIs too. Text-only coding models can be paired with a small local vision model for image input.

What are bee skills?

A skill is a markdown-defined capability you can run as bee <name>. You can add skills without putting more executables on your PATH or installing shell shims. Skills can provide prompts, commands or multi-step workflows.

Does bee work with hosted providers like OpenRouter?

bee supports OpenRouter, OpenAI, Anthropic and Gemini, plus any OpenAI-compatible endpoint configured in a few lines. It can also sign in to a ChatGPT account using OAuth. Use /model to move between local and hosted models.

Can bee run many agents at once, or overnight?

bee agents isolates each task in its own git worktree and merges it after the verify gate passes. bee swarm and bee fan distribute work across several agents. For unattended work, bee zzz makes small changes and commits or rolls back after each iteration.

Does bee help me understand what it changed?

bee asks the model to record a one-line reason for every file change and shows it beside the edit. bee explain reviews changes by request, while bee quiz asks you to predict the reason before revealing it.

Is bee free and open source?

bee is MIT-licensed, with source code, issues and releases at github.com/elhenro/bee. Releases provide pure-Go static binaries for macOS and Linux on amd64 and arm64. Windows is currently untested.
